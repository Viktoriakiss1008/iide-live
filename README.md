# Їде — табло приміських маршруток

Табло показує активні рейси, наступну зупинку, час прибуття та стан на дорозі. Водій публікує дані зі сторінки `driver.html`.

## Запуск сервера

У каталозі `public` виконайте:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\serve.ps1
```

Сервер друкує адресу локальної мережі, наприклад `http://192.168.31.106:8765/`.

- На телефоні водія відкрийте `/driver.html`.
- На телефоні пасажира відкрийте `/`.
- Телефони мають бути підключені до того самого Wi-Fi.

Рейси зберігаються на сервері в `.server-data/trips.json` і одразу доступні всім пристроям у мережі.

## Доступ через інтернет

Зараз увімкнений публічний HTTPS-тунель:

- Табло: https://a43e84ccd7ed22d1-92-52-135-40.serveousercontent.com/
- Для водія: https://a43e84ccd7ed22d1-92-52-135-40.serveousercontent.com/driver.html

Посилання працює, поки сервер і SSH-тунель залишаються запущеними на цьому комп’ютері. При першому переході безкоштовний Serveo показує сторінку попередження — натисніть «Continue to Site». Адреса може змінитися після перезапуску тунелю.
